📥 제출받는 법

학생이 만든 .json 파일을 어디로 걷고 · 무엇으로 읽는지 정리했습니다. 학생 쪽은 바뀌는 것이 없습니다 — 지금처럼 「📤 제출 파일 저장」을 누르면 됩니다.

먼저 결론
걷는 곳은 구글 설문지(파일 업로드 문항)가 가장 안전합니다. 파일이 드라이브 폴더에 자동으로 쌓입니다.
읽는 것은 「제출 파일 읽기」 도구에 파일을 통째로 끌어다 놓으면 됩니다.

1. 어디로 걷나 — 세 가지 방법

방법이런 점이 좋고 / 이런 점이 걸립니다
권장구글 설문지
(파일 업로드 문항)		 파일이 내 드라이브 폴더에 자동으로 저장되고, 누가 언제 냈는지 시트에 한 줄씩 남습니다. 학생은 폴더를 볼 수 없어 남의 파일을 지우거나 볼 수 없습니다.
학생이 구글 계정으로 로그인해야 합니다(학교 계정이면 그대로 됩니다).
드라이브 폴더를
공유해서 올리게 하기		 설정이 가장 빠릅니다. 다만 올릴 수 있게 하려면 편집자 권한을 줘야 하고, 그러면 학생이 남의 파일을 열어 보거나 지울 수 있습니다. 학급 전체에 쓰기에는 권하지 않습니다.
구글 클래스룸
과제로 받기		 클래스룸을 이미 쓰고 있다면 가장 편합니다. 제출·미제출이 자동으로 갈립니다. 받은 파일은 한꺼번에 내려받아 읽기 도구에 넣으면 됩니다.

2. 구글 설문지로 걷기 — 한 번만 만들면 계속 씁니다

구글 설문지를 새로 만듭니다 forms.google.com → 빈 양식. 제목은 「AI 수업 과제 제출」 정도면 됩니다.
질문을 네 개만 만듭니다 ① 반 (단답형) ② 번호 (단답형) ③ 이름 (단답형) ④ 제출 파일 (파일 업로드)
①②③은 필수로 켜 두세요. 파일 이름만으로는 누구 것인지 헷갈립니다.
④를 「파일 업로드」로 바꿉니다 질문 유형에서 파일 업로드를 고르면 “응답자의 드라이브에서…” 안내가 뜹니다. 계속을 누르세요.
· 특정 파일 형식 → 사용 안 함으로 두거나, 켤 거면 문서가 아니라 그대로 두는 편이 안전합니다(.json은 목록에 없습니다).
· 최대 파일 수 1, 최대 크기 1MB면 충분합니다. 제출 파일은 보통 10~50KB입니다.
어느 모듈인지 구분되게 합니다 모듈마다 설문지를 따로 만들거나, ⑤번 질문으로 「모듈 선택」(드롭다운)을 하나 추가하세요.
파일 안에도 모듈 이름이 들어 있어서, 읽기 도구에서 모듈별로 걸러 볼 수 있습니다.
학생에게 링크를 줍니다 보내기 → 🔗 링크 → URL 단축. 이 링크 하나면 학기 내내 씁니다.
수업 화면에 띄워 두면 학생이 QR 없이도 주소창에 칠 수 있습니다.
받은 파일을 내려받습니다 설문지 → 응답 탭에 시트가 만들어집니다. 파일은 내 드라이브의 「(설문지 이름) (파일 응답)」 폴더에 모입니다.
그 폴더를 열어 전체 선택 → 다운로드하면 ZIP으로 받아집니다. 압축을 풀면 .json 파일들이 나옵니다.
파일 이름이 이미 정리되어 있습니다
학생이 저장하면 파일 이름이 3단계A7_2학년3반_7_홍길동.과제제출.json 형태로 만들어집니다. 구글 설문지는 여기에 제출자 이름을 한 번 더 붙여 줍니다. 그래서 압축만 풀면 바로 읽힙니다.

3. 무엇으로 읽나

📥 제출 파일 읽기 — 전수 확인용

압축 푼 폴더째로 끌어다 놓으면 반 전체가 한 화면에 뜹니다. 누가 덜 냈는지 바로 보입니다.

  • 학생을 눌러 스텝별 답을 그대로 읽습니다
  • 나눠 준 틀 그대로 낸 것은 노란색으로 표시됩니다 — 안 쓰고 낸 것이 걸러집니다
  • 미제출자 찾기 — 명단을 붙여넣으면 안 낸 사람만 뽑아 줍니다
  • 엑셀(CSV)로 내보내기 — 한 줄에 한 학생, 열에 스텝별 답
  • 인쇄 · PDF — 골라서 종이로
제출 파일 읽기 열기

✅ 과제 채점·피드백 도구 — 한 명씩 채점할 때

한 명씩 열어 점수와 피드백을 적고 PDF로 만들 수 있습니다. 수행평가에 씁니다.

채점·피드백 도구 열기 ↗
둘 다 인터넷으로 파일을 보내지 않습니다. 브라우저 안에서만 열립니다. 학생 이름이 든 파일이라 이 점이 중요합니다.

4. 파일을 받지 않고 걷는 방법도 있습니다

학생이 구글 계정이 없거나, 파일 올리는 것이 번거로우면 「📋 제출 내용 복사」를 눌러 글로 붙여넣게 하면 됩니다.

  1. 구글 설문지에 장문형 질문 하나를 만듭니다 — 「제출 내용을 붙여넣으세요」
  2. 학생은 마무리 화면에서 📋 제출 내용 복사 → 설문지에 붙여넣기
  3. 응답 시트에 그대로 쌓입니다. 열에서 바로 읽고 정렬할 수 있습니다

다만 이 방식은 읽기 도구로 못 엽니다(파일이 아니라 글이라서요). 반 전체를 훑어볼 것이라면 파일 쪽이 낫습니다.

5. 학생에게 그대로 읽어 줄 안내

과제를 다 하면 아래 순서로 냅니다. 1. 마지막 화면에서 「📤 제출 파일 저장 (.json)」을 누릅니다. → 내려받기 폴더에 파일이 하나 생깁니다. 이름은 건드리지 마세요. 2. 선생님이 준 제출 링크를 엽니다. 3. 반 · 번호 · 이름을 적고, 방금 받은 파일을 올립니다. 4. 제출 후에도 그 화면은 그대로 두세요 — 다시 열면 이어서 할 수 있습니다. ※ 파일이 안 보이면 「다운로드」 폴더를 찾아보세요. ※ 휴대폰이면 「파일」 앱 → 다운로드에 있습니다.
한 가지만 주의
제출 파일에는 학생 이름과 반·번호가 들어 있습니다. 단톡방이나 공개 폴더에 올리지 말고, 위 방법 중 하나로 받으세요.
