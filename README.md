# 단계별 AI 수업

AI를 처음 쓰는 학생이 **한 스텝씩 따라가며** 익히도록 만든 수업 자료입니다.

🔗 **https://hongyul67-cpu.github.io/ai-step-master/**

---

## 전체 흐름

| 단계 | 내용 |
|---|---|
| 1단계 | AI 윤리 — 넣지 말 것 · 믿지 말 것 · 숨기지 말 것 |
| 2단계 | 다양한 AI 맛보기 + RCIF 프롬프트 |
| **3단계** | **공통 과제 모듈 — 같이 한 스텝씩** ← 이 저장소 |
| 4단계 | 각자 주제로 다시 해 보기 |

## 3단계 A트랙 (문서·글쓰기)

| 코드 | 모듈 | 이 모듈만의 장치 |
|---|---|---|
| A1 | 회의록 정리하기 | "메모에 없는 내용은 추가하지 마" → 원문과 문장 단위 대조 |
| A2 | 선생님께 메일 쓰기 | 용건이 사정보다 먼저 / 휴대전화 한 화면 |
| A3 | 학교에 건의하기 | 숫자를 지어내지 말고 `[조사 필요]`로 비워 두기 → 학생이 직접 조사 |
| A4 | 체험학습 보고서 쓰기 | "너는 그날 그곳에 가지 않았어" |
| A5 | 근로계약서 읽고 질문 뽑기 | "확실하지 않으면 확실하지 않다고 말해" → 공식 자료로 직접 확인 |

모든 모듈이 **같은 14스텝**을 씁니다.

```
S1 재료      S2 역할·상황만   ★S3 AI가 나에게 질문   S4 답하기
S5 뼈대만    S6 뼈대 수정①    S7 1차 초안           S8 전체 수정②
S9 부분 수정③  S10 사실 확인   S11 상대 입장에서 비판  ★S12 AI 없이 내 손으로
S13 사용 기록  S14 제출·비교
```

**S3(AI가 먼저 질문하게)** 와 **S12(AI 없이 내 손으로)** 가 이 수업의 승부처입니다.

## 파일 구조

```
index.html                     허브 — 여기서 시작
A1~A5_*.html                   학생 배포용 (모듈 내용이 파일 안에 들어 있음)
모듈편집기.html                 교사용 — 내용 수정 · 새 모듈 만들기
modules/*.json                 모듈 원본 (학생 화면 + 워크북 + 교사 가이드의 유일한 원본)
modules/보관/                   쓰지 않는 옛 모듈 보관
워드/                          학생용 워크북 · 교사용 운영 가이드 (.docx)
_템플릿/                        빌드 템플릿과 저작 스크립트
```

## 학생에게 나눠 줄 것

각 모듈의 **`A○_*.html` 파일 하나**면 됩니다. 그 파일 하나에 모든 내용이 들어 있어
**인터넷 없이도** 열리고, 브라우저를 닫아도 자동 저장됩니다.

## 교사가 내용을 고치려면

1. `모듈편집기.html` 열기 → `📂 열기`로 `modules/*.json` 불러오기
2. 프롬프트 · 스텝 · 체크리스트 · 평가표를 화면에서 수정
3. `💾 모듈 저장` → `📦 학생용 파일 만들기` → 새 HTML 배포
4. 인쇄물이 필요하면 `🖨 워크북 인쇄` / `🖨 교사 가이드 인쇄`

새 모듈은 `＋ 새 모듈`을 누르면 **14스텝 골격이 통째로** 나오므로 내용만 채우면 됩니다.

## 워드 파일을 다시 뽑으려면

```bash
python "_템플릿/build_all.py"
```

`modules/*.json` 하나에서 학생용 HTML · 워크북 · 교사 가이드 · 허브를 전부 다시 만듭니다.
(python-docx 필요)

## 제출과 채점

학생이 마지막 화면에서 저장한 `.과제제출.json` 은
[과제 채점·피드백 도구](https://hongyul67-cpu.github.io/ai-task-tools/)에서 그대로 열립니다.
